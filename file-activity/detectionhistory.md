# Windows Defender Detection History Files
Windows Defender Detection History files are forensic artifacts generated by Microsoft Defender Antivirus when it detects potentially malicious or unwanted resources. These artifacts are maintained as part of Windows Defender's Protection History.

Based on documented testing, Detection History files are created on systems with Windows Defender Real-Time Protection and cloud-delivered protection enabled when Defender detects a threat. Importantly, the creation of a Detection History file does not require the detected executable to have been executed.

### Behavioral Indications
 - [x] Behavioral - Execution (TA0002)

### Analysis Value
 - [x] Execution - Evidence of Execution
 - [x] File - Path
 - [x] File - Hash

## Operating System Availability
 - Windows Defender

## Artifact Location(s)
 - `%ProgramData%\Microsoft\Windows Defender\Scans\History\Service\DetectionHistory\[0-9]*\`

## Artifact Parsers
 - KAPE (Extraction and Parsing)
 - [defender-detectionhistory-parser](https://github.com/jklepsercyber/defender-detectionhistory-parser)

## Artifact Interpretation
Detection History files contain information about threats detected by Microsoft Defender Antivirus and the resources associated with those detections. The presence of a Detection History file indicates that Windows Defender recorded a detection. However, it does not independently establish that the detected executable was executed, successfully quarantined, or removed.

The artifact can contain the following information, depending on the type of detection:

- Threat name and classification (e.g., Trojan, RAT, PUA).
- Threat status, indicating whether the resource was detected, cleaned, quarantined, removed, allowed, or blocked.
- Resource path, including executable paths and Windows Registry locations.
- File hashes, including SHA-256, SHA-1, and MD5, when available.
- File size.
- Detection timestamp (ThreatTrackingStartTime), stored as a Windows FILETIME value in UTC.
- Associated user account.
- Spawning process, identifying the parent process associated with the detection.

> [!NOTE]
>  The user and spawning process fields should not be interpreted as definitive evidence of who created the file or which process originally introduced it to the system.

Detection History files can also contain information about Windows Registry resources. Depending on the threat type, these may include registry keys, registry values, startup entries, services, scheduled tasks, and other persistence-related resources.

## ThreatStatusID Interpretation
The ThreatStatusID field identifies the recorded status of the detection.

| Value | Status 3 |
| -------- | -------- |
| 0     | Unknown     |
| 1     | Detected     |
| 2     | Cleaned     |
| 3     | Quarantined     |
| 4     | Removed     |
| 5     | Allowed     |
| 6     | Blocked     |

These values are based on the documented [Detection History file format](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/defender/msft-mpthreatdetection) and should be validated against the corresponding Windows Defender version.

Possible event log correlations include:

- Event ID 1116: Malware or potentially unwanted software detected.
- Event ID 1117: Action taken against malware or potentially unwanted software.


## Example
In the following example, an EICAR test file, eicar.com, was downloaded. This activity generated a Windows Defender alert and produced a Detection History file located at:

```
C:\ProgramData\Microsoft\Windows Defender\Scans\History\Service\DetectionHistory\19\BA74399A-42A4-4774-95A0-B0758DE6C5A3
```

The artifact's creation time corresponds to the time Windows Defender detected the file, approximately 2024-04-18 16:24 UTC.
